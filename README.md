# Blockchain-Based GHG Emissions MRV Smart Contract

A blockchain-based Monitoring, Reporting and Verification (MRV) solution for maintaining transparent, tamper-resistant and auditable greenhouse gas (GHG) emissions records.

## Project Overview

This project implements a Solidity smart contract for recording and verifying greenhouse gas emissions data. The system uses blockchain technology to improve the integrity and auditability of emissions reporting.

## Key Features

- Manufacturing facility registration
- Authorised emissions reporting
- Role-based access control
- Immutable emissions records
- Emissions report hash storage
- Auditor verification
- Event logging

## Technologies

- Solidity
- Ethereum-compatible blockchain
- MetaMask
- Hardhat
